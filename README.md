# ScalaHosting Performance Testing

This repository supports the GoogieHost review of ScalaHosting by providing the performance-testing scripts and data files used to document uptime, time to first byte (TTFB), and load-test observations.

For the review, methodology, findings, and detailed analysis, read:

[ScalaHosting Review – GoogieHost](https://googiehost.com/blog/scalahosting-review/)
